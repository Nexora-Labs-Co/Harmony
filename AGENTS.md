# Harmony

Flutter + Rust hybrid music player. UI/state in Dart (`lib/`), heavy logic in Rust (`rust/crates/nexora_core`), FFI via `dart:ffi`.

## Commands

- `flutter pub get` — install Dart deps (run after `pubspec.yaml` changes).
- `cd rust && cargo build -p nexora_core --release` — build native core; output is `rust/target/release/nexora_core.dll` on Windows, `libnexora_core.so` on Linux.
- `flutter build windows --release` — Windows app bundle.
- `flutter build linux --release` / `flutter build apk --release` — Linux/Android.
- `flutter test` — widget tests (single smoke test in `test/widget_test.dart`).
- `flutter analyze` — static analysis (many pre-existing warnings; not a hard gate).

Packaging (Git Bash on Windows; uses `cygpath`):

- `./scripts/package.sh windows` — builds Rust + Flutter, copies `nexora_core.dll`, creates a zip.
- `./scripts/package.sh linux` / `android` / `all`.

## Structure

- `lib/services/rust_ffi.dart` — loads the native library; searches `exeDir` then `rust/target/{release,debug}`. Keep Windows `.dll` and Linux `.so` names in sync with Rust `crate-type = ["cdylib", ...]` and `name = "nexora_core"`.
- `rust/` — Cargo workspace (`crates/nexora_core`).
- `rust_builder/` — Flutter plugin glue for the Rust lib (platform plugin class `none`).
- `windows/`, `linux/`, `android/` — platform projects; `*/flutter/generated_plugins.cmake` and registrants are generated by Flutter — do not hand-edit.
- `assets/images/` must exist (referenced in `pubspec.yaml`).

## Windows gotchas

- The Windows build downloads no NuGet anymore: `permission_handler` was removed because it was unused and its `permission_handler_windows` plugin required NuGet/CppWinRT.
- `media_kit` pulls `libmpv-2.dll` via `media_kit_libs_audio`; ensure it ends up in `build/windows/x64/runner/Release/`.
- After `flutter build windows --release`, copy `rust/target/release/nexora_core.dll` into `build/windows/x64/runner/Release/` (the package script does this).
- Native asset dir is `build/windows/x64/runner/Release/`; app resolves the DLL relative to the executable.

## Verification order

Rust first, then Flutter, then package:

1. `cd rust && cargo build -p nexora_core --release`
2. `flutter build windows --release`
3. copy DLL (or run `scripts/package.sh windows`)
4. smoke-run `build/windows/x64/runner/Release/harmony.exe`
